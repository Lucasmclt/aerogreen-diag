# Note stratégique — AeroGreen Diag

## Pourquoi ce projet existe

AeroGreen Diag a été conçu comme un prototype portfolio pour démontrer ma capacité à transformer un problème B2B industriel en outil numérique structuré.

## Hypothèse de départ

Une PME industrielle peut recevoir une demande client ou fournisseur sur ses pratiques RSE numériques sans disposer d’un dossier de preuves clair.

## Choix de conception

- cibler une PME aéronautique fictive autour de Toulouse ;
- utiliser un diagnostic déclaratif plutôt qu’un audit ;
- produire un score indicatif, non officiel ;
- mettre les preuves au centre du projet ;
- générer un rapport compréhensible hors application.

## Limites assumées

Le projet ne mesure pas une empreinte carbone réelle, ne certifie rien et ne remplace pas un consultant RSE.

## Ce que le projet démontre

- cadrage produit ;
- compréhension métier ;
- structuration de preuves ;
- Streamlit / Python / SQLite / PDF ;
- storytelling tech-business.
